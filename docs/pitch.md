## Group Member B

### Scenario 1 - They Know What MCP Servers Are
Execllent. Now, you know that a team might host an MCP server online if everyone is using the same MCP capabilities. However, you can quickly rack up a large cloud bill, and for small teams we have found an alternative. If the team members are consistently working at the same time, why not allow one member to run the server locally, and share those capabilities with everyone else? 

### Scenario 2 - They Don't Know What MCP Servers Are 
Okay. It's actually quite simple. It's simply a server that an AI coding agent, such as GitHub Copilot or Claude Code, can talk to. The server has a catalogue of API's to collect and gather information from external platforms, extending its capabilities beyond working in the repo alone. You'll see a few examples of this as we demo. (Transition to Scenario 1). 

## Group Member C
This is Tether. It is a desktop app that acts a gateway to make this solution possible. A host user can connect their locally running MCP server to the gateway, then expose the MCP server to their teammates, who will connect remotely through the app. The teammates are then able to invoke the MCP capabilities from their own devices, effectively giving you the best of both worlds. Moreover, since it runs on your own hardware, you also gain privacy and the ability to control your own uptime and downtime.
